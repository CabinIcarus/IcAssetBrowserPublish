# IcAssetBrowserPublish

# 它是干嘛的?
它是一个资源管理器, 用于管理游戏开发时的资源，如果你也被系统的文件浏览器寻找资源慢所困扰，那你可以试试它。

# 它的功能
- 给资源添加Tag，描述，自定义名字（这些都是独立于文件的，不用担心源文件被修改）
- 预览资源（静态图片，音乐，GIF）
- 复制资源、符号链接创建
- AI功能（暂时只支持翻译功能，如何使用后续会说明）

# 教程

初次打开程序,请在右上角设置`工作路径`

![M1(FGT@_T0PD$H5FCN6QU4P](https://github.com/user-attachments/assets/a455c326-69d7-4143-89f6-fc6b83b1cdd5)

然后点击`文件夹`按钮选择文件夹

![image](https://github.com/user-attachments/assets/35fee88d-7bb7-46e4-93b7-b5b28cf7c059)

之后就可以在`菜单`添加`资源目录`啦

# AI的使用
1. 在`菜单/设置`中添加一个AI配置,AI支持`OpenAI`,`Ollama`
![image](https://github.com/user-attachments/assets/0f2b692f-dc53-40c0-abf3-fd3e2c80bfbb)
2. 添加后,使用它
![image](https://github.com/user-attachments/assets/053a1255-c74d-47a8-936d-4e25a2ece6cc)
3. 这时`菜单/AI`将变的可用
![image](https://github.com/user-attachments/assets/52ff6b55-230d-4145-96a8-eb0489bf4d4a)
4. 点击`开始分析资源`,AI将会在后台分析资源,你可以主动取消分析,已经分析的资源后续不会被分析
5. 如果对分析的结果不满意,你可以使用`清空分析记录`来释放分析的记录
6. 提示词调试过程,建议在AI分析开始后,进度条不在是动画状态你就可以取消它,验证一下提示词
7. `v1.4.7`版本,暂时没有针对特定资源的AI分析,将会在`v1.4.8`版本更新加入
8. AI处理的结果,可以悬浮资源查看
![image](https://github.com/user-attachments/assets/58123000-229f-4f4d-8e8d-f2b77996a7df)
